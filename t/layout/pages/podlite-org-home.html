How it works →

Write structured documents

Use named blocks and typed attributes for content and metadata.

Select blocks by name and attributes 

npx podlite query 'head1' docs/*.podlite --to json

Run checks after an edit

podlite lint reports a block left open, with its line. podlite test checks a document against assertions you write, for example that it has a code block in a given language.

Run lint and query after an agent edits a document: files, commands and output.

Bring your Markdown

Podlite reads .md files as Markdown, and a Podlite document can include a markdown block.

Why blocks

The CommonMark site says nothing in Markdown counts as a syntax error. The Podlite specification requires a parser to warn when inline formatting such as I<...> is left unclosed, and podlite lint reports it with the line.

Our goal is to make Podlite the best markup language for AI.
